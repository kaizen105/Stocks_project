# Stocks Project

This project contains machine learning models and data pipelines for analyzing stock data and predicting volatility.

## ML Model Findings

Based on the SHAP (SHapley Additive exPlanations) analysis of our machine learning models, we have found that the top drivers of volatility are **different from solely relying on the VIX (Volatility Index)**. The model identifies multiple other features and interactions that are more predictive of true volatility than the VIX alone.
